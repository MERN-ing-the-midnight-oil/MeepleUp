MeepleUp

Board game night made simple.

MeepleUp is event management built specifically for tabletop gamers. Whether you're already hosting regular game nights or thinking about starting one, MeepleUp makes it effortless.

Everything you need in one app:

  • Calendar and RSVP management
  • AI-powered board game cataloging (just snap a photo of your physical collection!)
  • Browse your group's collections to plan the perfect game night
  • Built-in discussion boards (no separate chat app required)

All the features of premium event platforms, tailored for tabletop gaming—at a fraction of the cost.
