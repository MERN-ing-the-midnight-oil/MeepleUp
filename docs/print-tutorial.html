MeepleUp App Tutorial

Complete Guide to Using Each Tab

MeepleUps Tab

The MeepleUps tab is where you manage your gaming events. Create new events, join existing ones, and organize your game nights.

Creating a New Event

Host your own recurring game night:

  1. Tap "Host New MeepleUp" from the Events screen
  2. Fill in event details:
    • Event Name (required) - e.g., "Tuesday Brewery Night"
    • Location (required) - General location description
    • Share Exact Address (optional) - Toggle to share precise location
    • Exact Address (if sharing) - Full address for GPS
  3. Set Schedule:
    • Tap calendar to select event dates
    • Set usual start and end times
    • Edit individual date times if different
  4. Add Description (optional) - Notes about the event
  5. Configure RSVP Settings:
    • Toggle RSVP required on/off
    • Set attendance limit (optional)
  6. Tap "Create Event"
  7. Save your join code - Share this 3-word code with friends
Joining Events

Join existing game nights:

  1. From Events screen, tap "Join MeepleUp"
  2. Enter the 3-word join code (e.g., "happy-dice-fun")
  3. Tap "Join"
  4. Event appears in your events list
Note: If you have a link to an event but aren't a member, you can contact the organizer to request access.
Managing Events

As an organizer, you can:

  • Edit event details (schedule, description, settings)
  • Add or remove dates via calendar picker
  • Edit times for individual dates
  • Update locations per date
  • Add notes to specific dates
  • Regenerate join code if needed
  • Archive events (moves to archived section)
  • Unarchive events from the archived section
Event Hub Features

Each event has three main tabs:

  • Event Tab: View event info, schedule, location, members, and RSVP to dates
  • Games Tab: Browse combined collections, propose games, rate proposed games, view attendee collections
  • Discussion Tab: Post messages, reply to posts, propose games you want to play, rate games others propose

List/Import Tab

The List/Import tab is where you manage your board game collection. Add games, organize your library, and keep track of your favorites.

Adding Games - Method 1: BoardGameGeek Import

Import your entire BGG collection:

  1. Go to Collection screen
  2. Tap "Import from BGG"
  3. Enter your BGG username
  4. Tap "Import Collection"
  5. Games are automatically added
Note: Your BGG collection must be set to public for this to work.
Adding Games - Method 2: AI Scanner

Use AI to identify games from photos:

  1. Go to Collection screen
  2. Tap the camera/scanner icon
  3. Take a photo of your game shelf
  4. AI identifies games in the photo
  5. Review and add identified games
Adding Games - Method 3: Text Search

Manually search and add games:

  1. Go to Collection screen
  2. Tap "Add Game"
  3. Search for game by name
  4. Select from search results
  5. Game is added to collection
Viewing Your Collection

Organize and browse your games:

  • Sorting Options: By Rating, By Category, or By Title
  • Filtering: Filter by category (Strategy, Family, Party, etc.), search by game name, view favorites only
Managing Games

Keep your collection organized:

  • Mark as Favorite: Open game details and tap star/crown icon
  • Delete Game: Open game details, tap "Remove from Collection", and confirm
  • Edit Game Info: Update number of plays, add personal notes, set your personal rating
Game Details View

Tap any game card to see:

  • Full game image
  • Title and year published
  • BGG rating (stars and numeric)
  • Player count range
  • Playing time
  • Age rating
  • Category badges
  • Game description
  • Your personal rating (if set)
  • Number of plays

Profile Tab

The Profile tab is where you manage your account, settings, and personal information.

Profile Management

Edit your personal information:

  1. Go to Profile screen
  2. Tap "Edit" on any field:
    • Name - Your display name
    • Bio - About you section
    • Location - Your general location
    • BGG Username - Link BoardGameGeek account
  3. Save changes

Profile Picture: Tap profile picture to change, upload new photo from device. Photo syncs across devices.

Notification Settings

Control how you're notified:

  • MeepleUp Changes: Toggle notifications for event changes, enable email notifications (optional)
  • Event Reminders: Toggle event reminder notifications, set hours before event (default: 24 hours)
  • Discussion Notifications: Choose frequency:
    • All Activity - Every post/comment
    • Daily Summary - Once per day
    • Mentions Only - Only when mentioned
    • Responses - Only replies to your comments
Account Management

Manage your account security:

  • Change Password: Go to Profile → Change Password, enter current and new password, confirm and save
  • Delete Account: Go to Profile → Delete Account, read warning, type "DELETE" to confirm, all data is permanently deleted
  • Logout: Tap "Logout" button in Profile screen to sign out
Availability Profile (Finding Players)

Set your availability to find other players:

  1. Go to Profile screen
  2. Scroll to "Availability"
  3. Add time slots when you're available:
    • Day of week
    • Start time
    • End time
    • Location
    • Notes (optional)
  4. Toggle "Looking for Matches"
  5. Set search radius (miles)

View Matches: See other users with overlapping availability, filter by distance, contact matched users.
