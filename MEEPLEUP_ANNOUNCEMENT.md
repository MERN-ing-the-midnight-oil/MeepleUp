I'm happy to announce the creation of Meepleup.Com. This project represents a culmination of modern web and mobile development technologies, bringing together the best of cross-platform development to solve a real problem for board game enthusiasts everywhere.

At its core, MeepleUp is built on React 19.1.0 and React Native 0.81.5, unified through Expo SDK 54. This architecture allows us to maintain a single codebase while delivering native experiences on iOS, Android, and the web. Expo's mature ecosystem handles everything from camera access to push notifications, in-app purchases, and OAuth authentication seamlessly across platforms.

The backend is powered entirely by Firebase, which has been a game-changer for rapid development. Firebase Authentication handles email/password and social sign-in flows (Google and Apple), while Cloud Firestore provides real-time synchronization that makes the app feel instantly responsive. When someone RSVPs to a game night or posts in a discussion thread, every member sees the update in real-time without manual refreshes. Firebase Storage handles image uploads, and Cloud Functions provide serverless capabilities for background processing.

One of the most exciting technical challenges was integrating with BoardGameGeek's XML API. The BGG API is notoriously rate-limited and returns data in XML format, so I built a robust service layer with exponential backoff retry logic, batch fetching capabilities, and intelligent caching in Firestore. Users can import their entire BGG collection—sometimes hundreds of games—and the app handles the API constraints gracefully.

The AI-powered game recognition feature uses Claude's Vision API to analyze photos of game shelves and identify board games automatically. This combines Expo's camera module for photo capture, image optimization before upload, and intelligent text extraction and matching against the BGG database. Users can literally snap a photo of their collection and have it cataloged automatically—it feels like magic, but it's really just thoughtful API integration and image processing.

State management uses React's Context API, organized into domain-specific contexts (Auth, Events, Collections, Availability, Subscriptions), keeping the codebase maintainable without Redux overhead. Each context manages Firestore listeners, local caching, and optimistic UI updates for snappy performance.

The routing architecture uses React Router v6 for web and React Navigation v6 for native, abstracted through a unified navigation hook so components don't need to know which platform they're running on. Performance optimizations include virtual scrolling, lazy loading, batch API operations, and Firestore's offline persistence for browsing collections without an internet connection. The subscription system integrates with Expo's in-app purchase APIs, handling both iOS and Android purchase flows with server-side verification. The codebase is fully typed with TypeScript and uses modern React patterns that adapt beautifully from mobile phones to tablets to desktop browsers.

What I'm most proud of technically is how seamlessly everything works together. A user can sign in with Google on their phone, create an event, invite friends via a three-word join code, import their BGG collection, scan additional games with AI, browse everyone's collections, propose games for an upcoming date, RSVP, and participate in discussions—all with real-time updates across devices. The technology stack makes this complexity feel simple to the end user.

MeepleUp represents what's possible when you combine modern development tools thoughtfully: React's component model, Firebase's real-time infrastructure, Expo's cross-platform capabilities, and AI-powered features that enhance rather than complicate the user experience. It's been an incredible journey building this, and I'm excited to see how the board game community uses it to make their game nights even better.
