### Add Games to Your Collection (3 Methods)
Go to **List/Import** tab. No collection will appear because you haven't added any games yet. 

**Import game titles with Image recognition:**
- In **List/Import** tab, tap the large camera icon button labeled "Import game titles with Image recognition"
- Test by snapping a photo of the image IMG_8702.PNG (attached). 
- AI identifies games automatically

**Import game titles by typing or dictating, or pasting them from another source:**
- In **List/Import** tab, tap the button labeled "Import game titles by typing or dictating, or pasting them from another source"
- Paste game titles in any format
- Test list: Wingspan, Ticket to Ride, Catan, Pandemic, Azul

**Import from BGG:**
- In **List/Import** tab, tap "Import from BGG"
- Enter any publically viewable BGG username, for example: "Martin" 
- Imports entire collection from BGG

### Event Hub Features

**Three Tabs:**
- **Logistics:** View details, members, RSVP, schedule
- **Gameplan:** Browse combined collections, propose games
- **Tabletalk:** Post messages, comment, interact

**RSVP:** In **Logistics** tab, tap Going/Can't Make It for each date. 

**Propose Games:** In **Gameplan** tab, browse games → Select game → Propose for event

### Additional Features
- **Private messaging:** Tap member profile → Send message
- **Manage collection:** In **List/Import** tab, favorite your games
- **Profile settings:** In **Profile** tab, update name, bio, notifications

## PRIVACY NOTES
- All groups are private and invitation-only via join codes
- Users only see events they've joined
- No public group discovery
- Members can leave anytime

## TECHNICAL INFO
- Integrates with BoardGameGeek XML API
- AI-powered game recognition via image analysis
- Firebase backend with offline support
- Push notifications (user-configurable)
